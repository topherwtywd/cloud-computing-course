# Google Cloud Platform (GCP) Research

## Brief Overview

**Google Cloud Platform (GCP)** is a cloud computing platform provided by Google. It offers cloud services that organizations can use to build, deploy, manage, and scale applications, websites, data systems, and other IT workloads.

## Global Infrastructure

GCP has a global infrastructure made up of **regions and zones** located in different parts of the world. This infrastructure allows organizations to deploy applications closer to their users and helps improve availability, performance, and reliability.

## Cloud Management Console

The **Google Cloud Console** is a web-based management interface used to create, configure, monitor, and manage Google Cloud resources. Users can manage services such as virtual machines, storage, databases, networking, and Kubernetes through the console.

## Four Core Services

1. **Compute Engine** – Provides virtual machines that can be used to run applications and workloads in the cloud.

2. **Cloud Storage** – Provides scalable object storage for files, images, videos, backups, datasets, and other types of data.

3. **Google Cloud VPC** – Provides networking capabilities that allow organizations to create and manage virtual networks for their cloud resources.

4. **Google Kubernetes Engine (GKE)** – Provides a managed environment for deploying, managing, and scaling containerized applications using Kubernetes.

## Three Advantages

1. **Strong AI and Machine Learning Capabilities** – GCP provides cloud technologies and infrastructure that support Artificial Intelligence and Machine Learning workloads.

2. **Kubernetes Support** – Google Cloud provides Google Kubernetes Engine (GKE), a managed Kubernetes service for deploying and managing containerized applications.

3. **Scalability** – GCP allows organizations to scale computing, storage, and other cloud resources according to their workload requirements.

## Typical Enterprise Use Cases

- **Artificial Intelligence and Machine Learning** – Organizations can use GCP services and infrastructure to develop and run AI and ML applications.
- **Application Hosting** – Businesses can host websites and applications using Google Cloud computing services.
- **Data Storage and Analytics** – Organizations can store and process large amounts of data using Google Cloud services.
- **Kubernetes Deployment** – Enterprises can deploy and manage containerized applications using Google Kubernetes Engine.
- **Web Applications** – Businesses can use GCP infrastructure to build and operate scalable web applications.
