## Comparison Questions

### 1. Which cloud provider offers the broadest range of services?

**AWS** is generally recognized for offering a very broad portfolio of cloud services across computing, storage, databases, networking, security, analytics, and other areas. Its extensive global infrastructure also supports a wide variety of workloads.

### 2. Which provider best integrates with Microsoft technologies?

**Microsoft Azure** is the best choice for organizations that already depend heavily on Microsoft technologies. Its integration with Windows Server, Microsoft 365, Active Directory-related services, and other Microsoft products makes it a natural option for Microsoft-based environments.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

**Google Cloud Platform (GCP)** is a strong choice for Artificial Intelligence, Machine Learning, and Kubernetes workloads. Google Cloud provides services such as Google Kubernetes Engine (GKE), Compute Engine, and specialized infrastructure for AI and ML workloads.

### 4. Which cloud platform would you personally choose and why?

I would personally choose **Google Cloud Platform (GCP)** because I am interested in Artificial Intelligence, Machine Learning, and modern cloud technologies. GCP also provides strong Kubernetes capabilities and scalable infrastructure that can support different types of applications.
