# Amazon Web Services (AWS) Research

## Brief Overview

**Amazon Web Services (AWS)** is a cloud computing platform provided by Amazon. It offers a wide range of cloud services that organizations can use to build, deploy, manage, and scale applications and IT infrastructure.

## Global Infrastructure

AWS has a global infrastructure made up of **Regions and Availability Zones**. These locations allow organizations to deploy applications and services in different parts of the world while improving availability, reliability, and performance.

## Cloud Management Console

The **AWS Management Console** is a web-based interface used to access and manage AWS services. Users can create, configure, monitor, and manage resources such as virtual machines, storage, databases, networks, and security services.

## Four Core Services

1. **Amazon EC2** – Provides virtual servers that can be used to run applications and workloads in the cloud.

2. **Amazon S3** – Provides scalable object storage for files, images, videos, backups, and other types of data.

3. **Amazon VPC** – Allows users to create and manage isolated virtual networks for AWS resources.

4. **AWS IAM** – Provides identity and access management for controlling who can access AWS resources and what actions they can perform.

## Three Advantages

1. **Wide Range of Services** – AWS provides many services for computing, storage, databases, networking, security, analytics, and other cloud requirements.

2. **Scalability** – AWS allows organizations to increase or decrease computing resources based on their workload and demand.

3. **Global Infrastructure** – AWS provides cloud infrastructure in many locations around the world, helping organizations serve users in different regions.

## Typical Enterprise Use Cases

- **Application Hosting** – Businesses can host web and enterprise applications using AWS computing services.
- **Data Storage and Backup** – Organizations can use Amazon S3 to store files, backups, and other data.
- **Database Management** – Businesses can use AWS database services to manage application data.
- **Website Hosting** – AWS can provide the infrastructure needed to host websites and web applications.
- **Disaster Recovery** – Organizations can use AWS services to create backup and recovery solutions for their IT infrastructure.
